## Vidéo de démonstration du logisticien : la remorque

**Quoi** : (1) le seed de démo gagne une remorque éligible (`DEMO-REM-001`, type `remorque`, papiers valides, hors atelier), réconciliée à chaque passage ; l'ancienne mission de démo est supprimée avec son affectation, donc la remorque est libre à chaque rejeu. (2) `e2e/demo/04-logistique.spec.ts` choisit la remorque à l'étape d'affectation de l'assistant (camion, remorque, chauffeur), vérifie en base que l'affectation de la mission porte `trailer_id` (et l'immatriculation de la remorque), puis montre la carte `mission-trailer` de la fiche mission avec une pause. (3) `mark()` dans `e2e/demo/helpers.ts` : repères de montage écrits dans `DEMO_MARKS_FILE` si la variable est définie, sans effet sinon. (4) la vidéo `client/public/demos/logistics.mp4` est refaite.
**Comment** : base Postgres locale dédiée `fleet_test_demo_remorque`, serveur local sur cette base (aucune URL Neon dans l'environnement), tournage en 1920x1080 avec une config non versionnée, deux passages de suite verts (idempotence). Montage avec le même pipeline que les autres profils : voix française Guillaume, débit 0,88, sous-titres 52 px, -15 LUFS. Les phrases inchangées reprennent les enregistrements vocaux existants ; les nouvelles (camion, remorque accrochée au camion, fiche de mission avec remorque, lancement, livraison, clôture) sont générées avec la même voix. Les écrans carburant et documents de la fin sont repris de l'ancien tournage (écrans sans lien avec la remorque).
**Pourquoi** : la vidéo datait d'avant l'affectation d'une remorque (assignments.trailer_id) : le logisticien n'y choisissait que le camion et le chauffeur, alors qu'il compose désormais l'attelage complet.
**Preuve** : `E2E_DEMO=1 node node_modules/@playwright/test/cli.js test e2e/demo/04-logistique.spec.ts` (1 sur 1, deux fois de suite, base locale) ; `npm run check` ; `npm test`.
