# Documentation

Ce dossier regroupe toute la documentation projet par thème.

## Arborescence

- `docs/qa/`: plans QA, cahiers de test, guides de validation
  - **`docs/qa/COMPTES_ENVIRONNEMENT.md`**: logins réels de la base Neon courante (référence pour tous les tests)
- Tests automatisés : `tests/README.md` (unit / integration / contract) et `e2e/README.md`
- `docs/guides/`: guides utilisateurs et profils d'accès
- `docs/planning/`: roadmap, planification, sprints
  - **`docs/planning/EVOLUTION_ATELIER_RECEPTION_QC.md`**: backlog atelier interne (réception, QC, main-d'œuvre) inspiré d'atelier2026 — à ne pas implémenter tant que le flux OT + magasin n'est pas stable
  - **`docs/planning/EVOLUTION_PROCESS_TIMELINE.md`**: timeline visuelle multi-profils (où on en est, qui doit agir) — composant unique, d'abord sur les demandes de pièce
- `docs/reports/`: rapports et états d'avancement
- `docs/analysis/`: analyses techniques et matrices d'écarts
- `docs/meta/`: documentation annexe (ex: contexte Replit)

## Note

Les README proches du code restent dans leurs dossiers techniques (`e2e/README.md`, `scripts/README-SEEDING.md`).
